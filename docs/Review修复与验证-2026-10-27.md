**同步脚本使用变化**

旧入口仍默认 dry-run，并保留原输入文件默认值。现在需要 API Bearer 凭据，支持
`--token-file` 或 `TRADE_ACCESS_API_TOKEN`；不再直接连接设备。

```bash
.venv/bin/python scripts/reconcile_firewall_to_ip_ports.py \
  --api-base-url http://127.0.0.1:8000 \
  --token-file .runtime/api-token \
  --input 最新ip_ports.json \
  --audit-output .runtime/inventory-sync/audit.json
```

凭据文件权限必须是 0600 或 0400。确认完整清单的增删计划后，加 `--execute` 执行。
首次切换 API 路径使用新的审计文件；后续恢复同一批次使用相同审计路径。输入仍按
完整目标清单处理，不在清单中的业务 IP/端口会被规划撤销。

**连接配置部署变化**
