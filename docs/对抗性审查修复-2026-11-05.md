## 历史/共享应用的处理边界

本次选择明确拒绝无法安全自动处理的配置，不自动改写共享应用。快照及一致性检查仍可读取合法历史对象；变更任务遇到绑定目标 IP 的此类对象，返回 `manual_intervention_required`，需要人工确认归属并迁移后重试。

无账本时，预检发现问题即停止，尚未执行配置。有账本、完整 deny 或恢复中的任务沿用原有执行顺序，最终验收仍检查这些绑定；此时标准对象可能已发生变化，但任务不会报告撤销成功。错误信息会指出需人工检查的应用，账本按已有失败回滚规则处理。该修复不宣称对设备进行了自动事务回滚。

用户角色锁协调本应用使用同一数据库的管理请求；它不是 Keycloak 与 SQLite 之间的分布式事务，也不锁定 Keycloak 管理控制台的外部操作。
