**部署与操作**

新增可选环境变量，API 与 worker 共用的示例见
[trade-access.env.example](../config/production/trade-access.env.example)：

```text
TRADE_ACCESS_API_KEYCLOAK_JWKS_REFRESH_MIN_INTERVAL_SECONDS=10
```

实际冷却不超过 `TRADE_ACCESS_API_KEYCLOAK_JWKS_CACHE_SECONDS`。Keycloak 应先发布
新公钥再切换签名；新 `kid` 在冷却期内首次出现时可能暂时返回 401，冷却结束后
重试可触发刷新。协调范围是同一个 API 进程；多进程分别维护缓存和冷却。

CLI 使用 Huawei 命令回显作为读取边界，未读到回显或识别不到结果提示符时按预算
超时退出。每条业务 `display` 查询增加一次短的只读同步查询，设备需支持现有查询
流程使用的 `display current-configuration | include`，以及临时会话分页设置。
完整撤销不需要公共基线，仍可能因
某台归属检查或执行失败而留下部分
节点已完成的状态，须依据逐台任务结果处理。

本轮未连接真实 Keycloak。针对 `192.168.6.54` 完成了 7 步只读真机验证：临时分页
设置被接受，用户/系统/虚拟系统三个视图下的过滤查询及随机标记同步均成功，版本
查询成功。另在虚拟系统读取 2502 行应用配置，未出现分页提示，返回结果没有混入
随机标记同步内容。只验证读取和会话级设置，没有执行 IP/端口变更、commit 或 save；SSH
会话已关闭，临时设置随会话结束失效。本轮结论不包含真实业务流量或故障注入验收。
